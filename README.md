Minimal New Tab is a minimal and modern browser start page with a clean dark interface. It provides quick access to multiple search engines...

## What it does

Minimal New Tab lets you:

* search using multiple search engines
* enjoy a clean, distraction-free dark interface

The project is focused on creating a simple and fast new tab experience... :)

## Motivation

I built this project to experiment with Tailwind CSS and create a minimal new tab page that is both clean and practical for everyday use... 

## Tech Stack

* HTML
* Tailwind CSS
* JavaScript (React Vite)
* News API (Inshorts)

## Future Plans

* Add customizable shortcuts.
* Allow users to create and manage quick tasks.
* Add more personalization options.
* Support additional search engines and widgets.
